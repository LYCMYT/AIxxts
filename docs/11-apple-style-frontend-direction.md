# Apple 风格前端优化方向

## 参考来源

- `VoltAgent/awesome-design-md`
- `design-md/apple/DESIGN.md`
- 本地 `design-taste-frontend` 技能审查规则

## 适配判断

AIxxts 是内部 AI 行业情报工作台，不是营销官网。因此不照搬 Apple 官网的摄影、产品大图、超大 hero 或商业落地页节奏，只抽取适合内部产品 UI 的部分：

- 白色内容表面
- `#f5f5f7` 浅灰画布
- `#1d1d1f` 近黑主文字
- `#7a7a7a` 次级文字
- `#0066cc` 单一动作蓝
- 细分割线和弱阴影
- 系统字体栈
- 低装饰、强可读、明确状态

## 本阶段落地规则

1. 首页第一屏继续直接展示今日精选，不新增营销 hero。
2. 页面背景统一使用浅灰画布，不再使用整页装饰渐变。
3. 主面板统一使用白色实体表面，减少玻璃拟态和大投影。
4. 导航、按钮、表格、表单共享同一套 token，不为单页单独造视觉语言。
5. 主操作使用动作蓝，状态色只用于真实的成功、失败、警告语义。
6. 卡片圆角控制在 `14px` 到 `18px` 范围内，复杂表格和输入使用更小半径。
7. hover 只改变边框、浅底色或弱阴影，不使用 glow。
8. 移动端保留横向导航和卡片列表可读性，不把信息密度压成营销卡片。

## 已调整范围

- 全局 CSS token：颜色、分割线、半径、阴影、focus 色。
- App shell：顶部导航更低、更轻，移除不必要阴影。
- 今日精选：首页头部面板改为白色实体面板。
- 历史回看和内容详情：头部面板统一为白色、弱阴影。
- 管理后台：整页背景、管理区块、表格框、输入框、统计卡和锚点导航统一为产品 UI 风格。
- 开发进度页：去除整页渐变和玻璃面板，统一面板和按钮样式。

## 后续检查

- 用 1440px 和 390px 视口检查首页、历史页、管理页、进度页。
- 检查长标题、长来源、空状态、失败状态不会撑破卡片。
- 若后续引入 shadcn/Radix，仍以这些 token 为主题基线。
